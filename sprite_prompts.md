## Generation Tips

1. **Always specify exact pixel dimensions** in the prompt
2. **Request "top-down view"** for all sprites (the game uses overhead perspective)
3. **Mention "pixel art" style** to get clean, crisp edges
4. **Use "EXACTLY [size] pixels"** to enforce size requirements
5. After generation, **verify the exact dimensions** before saving
6. If generated at wrong size, **resize using Nearest Neighbor** interpolation to preserve pixel art look
7. Save all files as **PNG with transparency** where appropriate
